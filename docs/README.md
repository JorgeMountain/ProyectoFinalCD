# Project Documentation

This folder keeps the long-form project material out of the repository root while preserving the technical evidence needed for review.

## Files

- `commands_es.md`: practical command cookbook for offline tests, live camera tests, BER, and troubleshooting.
- `code_map_es.md`: file-by-file code map and modification guide.
- `defense_guide_es.md`: concise guide for explaining the project in a presentation.
- `theory_guide_es.md`: communication theory notes behind the implementation.
- `decision_record_es.pdf`: summarized implementation decisions.
- `design/ook_4ask_design.md`: 4-ASK design notes.
- `design/ook_4ask_implementation_plan.md`: implementation plan used for the OOK / 4-ASK extension.
